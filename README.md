
# Weather App 🌤️

Aplicación de clima desarrollada en React con Vite, Tailwind CSS y PrimeReact.

## 🚀 Instalación

1. Clona el repositorio:
 git clone git@github.com:saidaJimenez/Weather-app.git

2. Instala las dependencias:
 npm install

3. Configura la API Key de OpenWeatherMap en `.env` tienes que crearlo en la raiz de la aplicacion .

4. Inicia la aplicación:
npm run dev


## 📌 Tecnologías Utilizadas
- React con Vite
- Tailwind CSS
- PrimeReact
- Axios
- OpenWeatherMap API
